## How to record a new entry

```bash
# Full benchmark (takes ~30 s on CPU):
python3 Python/bench_secp256k1.py --log

# Quick smoke test (reduced iterations):
python3 Python/bench_secp256k1.py --quick
```

The `--log` flag appends a new row to this file.
